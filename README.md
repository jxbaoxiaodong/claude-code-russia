# Claude Code в России

Самый быстрый способ получить работающий Claude Code в РФ:

1. **Готовое окружение + подписка** — сервер с Claude, прокси и Max-тарифом уже настроен:
   [claude.tokenbuddy.cc](https://claude.tokenbuddy.cc/?src=gh_claude-code-russia)
   (выдача в течение минут после оплаты, USDT или локальные способы).
2. **Claude API по эндпоинту** — если нужен API, а не подписка:
   [tokenbuddy.cc](https://tokenbuddy.cc/?src=gh_claude-code-russia) —
   Anthropic-совместимый эндпоинт, оплата за токены, автоматическое переключение источников.

Пример (API):

```bash
export ANTHROPIC_BASE_URL=https://tokenbuddy.cc
export ANTHROPIC_API_KEY=***
claude
```

Модели: claude-sonnet-5 / claude-opus-5 (и -full — полный лимит). Цены — на сайте, оплата USDT.

Это community quickstart-репозиторий проекта [tokenbuddy.cc](https://tokenbuddy.cc).
